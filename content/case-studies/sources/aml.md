# Background
Financial institutions face strict regulations regarding anti-money laundering (AML). Analysts need tools to help them track thousands of daily transactions, identify unusual patterns, and act quickly to prevent fraud or illegal activity.
<callout icon="💡" color="gray_bg">
	We designed an **AML system interface** that turns complex transaction data into clear, actionable insights for compliance teams.
</callout>
# Challenge
The existing workflows were overloaded with spreadsheets and disjointed tools, making it difficult for analysts to spot suspicious activity efficiently. The system needed to:
<columns>
	<column ratio="100">
		<callout color="gray_bg">
			- Aggregate large volumes of transaction data in real time 
			- Help analysts quickly filter, search, and review cases 
		</callout>
	</column>
	<column ratio="100">
		<callout color="gray_bg">
			- Highlight suspicious patterns and anomalies for investigation 
			- Provide dashboards for managers to track alerts, team workload, and resolution status
		</callout>
	</column>
</columns>
# Goal
Our goal was to create a **specialized tool for AML analysts** that reduces complexity, improves detection accuracy, and streamlines the investigation process. The system had to support both day-to-day case review and higher-level monitoring for compliance officers.
# Solution
We designed a **modular dashboard system** tailored to AML workflows:
<columns>
	<column>
		<callout color="gray_bg">
			**Transaction monitoring**
			Analysts can search, filter, and review transactions with real-time status updates.
		</callout>
		<callout color="gray_bg">
			**Case management**
			Suspicious items are grouped into cases with clear timelines, alerts, and investigation notes.
		</callout>
	</column>
	<column>
		<callout color="gray_bg">
			**Data visualization** 
			Charts and distribution graphs highlight anomalies, helping analysts spot patterns at a glance.
		</callout>
		<callout color="gray_bg">
			**Admin dashboards:** 
			Managers can see team performance, case resolution status, and workload distribution.
		</callout>
	</column>
</columns>
The interface balances **clarity and density,** showing critical data without overwhelming the user and ensuring analysts can act quickly when risks appear.

# Results
The AML system improved analysts’ ability to **detect suspicious transactions faster and more confidently**. By combining structured workflows with intuitive dashboards, the tool reduced manual work, helped teams prioritize high-risk cases, and supported compliance with regulatory standards.
